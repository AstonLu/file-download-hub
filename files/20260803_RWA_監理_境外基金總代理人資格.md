TL;DR：券商可依法擔任境外基金總代理人，但須持續符合資本、財務、監理紀錄、人力、系統及保證金等門檻；總代理人資格只是基金申請的前置 Gate，不代表個別基金已獲准在臺銷售。

# 境外基金總代理人資格與持續義務

## 一、核心定位

境外基金管理機構或其指定機構，必須委任**單一總代理人**，才能在臺代理其基金募集及銷售；總代理人可由經核准營業的證券投資信託事業（SITE）、證券投資顧問事業（SICE）或證券經紀商擔任。[1] #事實

總代理人不是單純行政窗口，而是臺灣市場的主要法遵與投資人保護責任主體，負責基金申請、資訊揭露、通路管理、交易申報、NAV公告及重大事件處理。[1] #事實

> **So What：** 券商若要自建總代理能力，真正門檻不只新臺幣7,000萬元資本額與3,000萬元起跳的營業保證金，而是必須建立可持續執行 KYP、通路監督、申報與投資人服務的完整營運能力。#判斷

## 三、營業保證金級距

除僅代理境外ETF者外，總代理人應向符合條件之金融機構提存營業保證金。[1] #事實

| 代理境外基金管理機構家數 | 應提存金額 |
|---:|---:|
| 1家 | 新臺幣3,000萬元 |
| 2家 | 新臺幣5,000萬元 |
| 3家 | 新臺幣7,000萬元 |
| 4家 | 新臺幣9,000萬元 |
| 5家 | 新臺幣1億1,000萬元 |

保證金可用現金、銀行存款、政府債券或金融債券提存，不得設定質權、提供擔保或分散於不同金融機構；更換提存機構或提取保證金須經SITCA轉報金管會核准。[1] #事實

> **成本判斷：** 3,000萬元不是費用，但屬長期受限制資金；券商應以資金占用成本、法遵人力及系統建置成本，而非僅以名目資本額評估商業可行性。#推論

## 四、法定最低人力不等於實際營運最低配置

《境外基金管理辦法》第16條只明定至少3名業務人員與適足內稽；金管會問答集進一步說明，總代理業務通常涉及通路服務、產品分析、投資人服務及境外行政服務，應配置至少3名通路服務人員、1名內部稽核人員與1名產品分析人員，且至少1名產品分析人員須符合投信基金經理人資格。[2] #事實

因此，單純以「3名業務員」估算自建總代理團隊會低估實際資源需求。#判斷

## 五、資格必須持續維持

總代理人取得基金核准後，仍須持續履行下列核心義務：[1] #事實

| 義務類型 | 主要工作 | 法規依據 |
|---|---|---|
| 日常申報 | 每營業日申報前一日申購、買回、轉換金額及單位數 | 第13條第1項 |
| 月報 | 每月終了後10個營業日內編具月報；部分投資比率資料得次月底前補送 | 第13條第2項 |
| 財務報告 | 公告基金年度財報及中文簡譯；註冊地要求半年度財報者亦同 | 第13條第3項 |
| NAV | 每營業日公告基金單位淨資產價值 | 第14條 |
| 通路監督 | 發現銷售機構違法、逾權或損害投資人權益，應立即督促改善並通知金管會 | 第15條 |
| 重大事件 | 基金合併、清算、終止臺灣銷售、變更管理機構等，須依事件類型申報、核准及公告 | 第12條 |
| 代理變更 | 總代理人變更或終止須經金管會核准，並辦理公告及投資人通知 | 第17條 |

總代理人若不再符合第9條資格，金管會得退回或不核准後續基金案件；已核准基金亦可能面臨監理處置。[1] #事實
